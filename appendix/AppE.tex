\chapter{Symbolic validation of \texorpdfstring{$h_{22}$}{h22} and
         \texorpdfstring{$h_{21}$}{h21}}
\label{ap:symb-val}

This appendix documents the symbolic validation of the ARES expansion
coefficients $h_{22}$ and $h_{21}$ against the SCET subtraction coefficients
$\mathcal{C}^{(2)}_1$ and $\mathcal{C}^{(2)}_0$ of
Eqs.~\eqref{eq:C21} and~\eqref{eq:C20}, discussed in
Sec.~\ref{subsec:NNLL-coeff}. The complete \textsc{Mathematica} notebook is
available at Ref.~\cite{peake2026validation}.

Within the notebook, the ingredients of Sec.~\ref{ap:subtract-ingred} and the
ARES coefficients of Eqs.~\eqref{eq:h11}--\eqref{eq:h21} are entered
directly. Uppercase symbols denote the full expansion of a coefficient,
following Eq.~\eqref{eq:subt-mn-exp}, and the shorthand \texttt{tot[m,n]}
collects the four functions at a given order and power of the logarithm (see below). The
remaining correspondence with the notation of this thesis is given in
Table~\ref{tab:mma-symbols}; symbols appearing only in the full notebook are
documented there.

Following Eq.~\eqref{eq:coeff-convent}, $\mathcal{C}^{(2)}_1/8$ should
reproduce $h_{22}$ and $\mathcal{C}^{(2)}_0/(-4)$ should reproduce $h_{21}$.
Since $h_{10}$, $h_{11}$ and $h_{12}$ have already been validated, the
cross-terms $\mathcal{C}^{(1)}_1\cdot\mathcal{C}^{(1)}_{-1}$ and
$\mathcal{C}^{(1)}_0\cdot\mathcal{C}^{(1)}_{-1}$, corresponding to
$h_{10}\cdot h_{12}$ and $h_{10}\cdot h_{11}$ in the ARES cumulant expansion,
are known independently and can be removed to isolate the contributions
corresponding to $h_{22}$ and $h_{21}$,

\begin{lstlisting}[style=mma]
tot[m_, n_] := J[m, n] + B1[m, n] + B2[m, n] + S[m, n];

C21 = (tot[2,1] + H1SCET tot[1,1]
    + 2 (J[1,0] B1[1,0] + J[1,0] B2[1,0] + B1[1,0] B2[1,0] + ... )
    - \[Pi]^2/3 (B1[1,1] B2[1,1] + B1[1,1] S[1,1] + ... )
    + B1[1,1] J[1,-1] + B2[1,1] J[1,-1] + ... );

C20 = (tot[2,0] + H1SCET tot[1,0]
    - \[Pi]^2/6 (B1[1,0] J[1,1] + B2[1,0] J[1,1] + ... )
    + 2 Zeta[3] (B1[1,1] B2[1,1] + B1[1,1] S[1,1] + ... )
    + B1[1,0] J[1,-1] + B2[1,0] J[1,-1] + ... );

C1m1   = tot[1,-1] + H1SCET;
C21Rem = C21 - C11 C1m1;
C20Rem = C20 - C10 C1m1;
\end{lstlisting}

\noindent
while the ARES coefficients are taken directly from
Eqs.~\eqref{eq:h11}--\eqref{eq:h21},

\begin{lstlisting}[style=mma]
h11 = ((g[1,0] + g[2,0] + g[3,0])
    - 2 Ck[1] Log[(Q[1,2]^2 Q[1,3]^2)/(Q[2,3]^2 M Q[1])] + ...
    - P[1,0] - P[2,0]);

h22 = (h11^2/2 - \[Pi]^2/3 Ctot^2 - K1 Ctot
    + 2 \[Pi] \[Beta]0 (-2 (Ck[1] + Ck[2] - Ck[3]) Log[Q[1,2]^2/Qresum^2]
        + g[1,0]/2 - 3 Ck[1] Log[Qresum^2/(M Q[1])] - 1/2 P[1,0] + ... )
    + 4 \[Pi] Ctot \[Beta]0 Log[Qresum/\[Mu]R]);

h21 = (-K1 ((Ck[1] + Ck[2] - Ck[3])
             (Log[Q[1,2]^2/(M Q[1])] + Log[Q[1,2]^2/(M Q[2])]) + ... )
    + 2 \[Pi] \[Beta]0 (ChcRec[1] + ChcRec[2] + ChcRec[3])
    + 2 Ctot^2 PolyGamma[2, 1]
    - gA[1,1] - gA[2,1] - gA[3,1] - (P[1,1] + P[2,1]));
\end{lstlisting}

\noindent
The $h_{22}$ comparison agrees exactly. For $h_{21}$, the comparison leaves a
residual proportional to $\gamma^{(1)}_\ell$, which does not vanish
symbolically because the SCET and ARES conventions for $\gamma^{(1)}_\ell$
differ (cf.\ Eqs.~\eqref{eq:gammal1-flav},~\eqref{eq:gamma-1-SCET-q}
and~\eqref{eq:gamma-1-SCET-g}). Substituting explicit values for the
$q\bar{q}\to Zg$ channel makes the residual vanish exactly; the other channels
follow analogously.
\begin{lstlisting}[style=mma]
C21Rem - 8 h22 // FullSimplify

(* Out: 0 *)

g1Res = C20Rem + 4 h21 // FullSimplify

(* Out: (1/2)(-g[1,1] - 8 gA[1,1] - g[2,1] - 8 gA[2,1]
               - g[3,1] - 8 gA[3,1] - 2 Ctot gs1) *)

g1Res /. {g[1,1] -> ..., gA[1,1] -> ..., gs1 -> ...,
          Ck[1] -> CF, Ck[2] -> CF, Ck[3] -> CA} // FullSimplify

(* Out: 0 *)
\end{lstlisting}
