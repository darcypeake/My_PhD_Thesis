\chapter{DISGenkt FastJet contrib}
\label{ap:DIS-fastjet}

The generalised-$k_t$ jet algorithm for Deep Inelastic Scattering presented in
Chapter~\ref{chapter:DIS} has been implemented as the
\href{https://repo.hepforge.org/source/fastjetsvn/browse/contrib/contribs/DISGenkt}{\texttt{DISGenkt}}
plugin to \textsc{FastJet} as part of \texttt{fjcontrib}. Relevant parts of the implementation are outlined below.

The pairwise distance $d_{ij}$ and beam distance $d_{iB}$,
defined in Eq.~\eqref{eq:dij-diB-ouralg}, are evaluated by the
\texttt{DISBriefJet} class. 
\begin{lstlisting}[caption={Implementation of the pairwise distance and 
beam distance. }]
double DISBriefJet::distance(const DISBriefJet * jet) const {
  double dij = 1 - _nx*jet->_nx
                 - _ny*jet->_ny
                 - _nz*jet->_nz;
  dij = dij * fmin(_E2p, jet->_E2p) / _dij_norm;
  return dij;
  
double DISBriefJet::beam_distance() const {
  return (1 - _beam_sign * _nz)*_E2p;  
}
\end{lstlisting}
The clustering sequence is performed using the \textsc{FastJet}
nearest-neighbour heuristic (\texttt{NNH}) class. If the minimum is $d_{ij}$ ($j\geq0$),
 jets $i$ and $j$ are merged, whereas if it is $d_{iB}$ ($j<0$), jet $i$ is declared
final and removed from the clustering.
\begin{lstlisting}[caption={Main clustering loop.}]
void DISGenktPlugin::run_clustering(
    fastjet::ClusterSequence & cs) const {
  int njets = cs.jets().size();
  DISjetInfo info(p(), beam_sign(), R());
  NNH<DISBriefJet,DISjetInfo> nnh(cs.jets(), &info);

  while (njets > 0) {
    int i, j, k;
    double dij = nnh.dij_min(i, j);
    if (j >= 0) {
      cs.plugin_record_ij_recombination(i, j, dij, k);
      nnh.merge_jets(i, j, cs.jets()[k], k);
    } else {
      cs.plugin_record_iB_recombination(i, dij);
      nnh.remove_jet(i);
    }
    njets--;
  }
}
\end{lstlisting}
The macrojet is then identified as the
jet with the largest DIS longitudinal projection,
$E-\mathrm{beam\_sign}\cdot p_z$.
\begin{lstlisting}[caption={Identification of the macrojet.}]
int DISGenktPlugin::find_idx_macrojet(
    const std::vector<PseudoJet>& jets) const {
  double best = 0.0;
  int idx = -1;
  for (size_t i = 0; i < jets.size(); ++i) {
    double proj = jets[i].E() - beam_sign() * jets[i].pz();
    if (proj > best) {
      best = proj;
      idx  = static_cast<int>(i);
    }
  }
  return idx;
}
\end{lstlisting}
A function is also provided to sort jets by decreasing DIS longitudinal projection.
\begin{lstlisting}[caption={Sorting jets by DIS longitudinal projection.}]
std::vector<PseudoJet> DISGenktPlugin::sorted_by_zjet(
    const std::vector<PseudoJet> & jets) const {
  std::vector<double> zproj(jets.size());
  for (size_t i = 0; i < jets.size(); i++) {
    zproj[i] = -(jets[i].E() - beam_sign() * jets[i].pz());
  }
  return objects_sorted_by_values(jets, zproj);
}
\end{lstlisting}
This is similar to the \texttt{sorted\_by\_pt(...)} function in \textsc{FastJet}
which sorts the jets by decreasing $p_t$.
